# 台股單筆投資回測

這是一個純前端的台股歷史回測頁面。輸入股票代號、回測起訖日期及本金，估算持有期間的股利、手續費、證券交易稅、淨利與淨報酬率。

## 使用方式

1. 開啟網站。
2. 輸入台灣股票代號、開始日、結束日及單筆本金（新台幣 100,000 至 20,000,000 元）。
3. 可展開進階設定，依券商實際費率調整買進／賣出手續費與交易稅。
4. 按「開始回測」。

資料由 FinMind 公開資料服務取得，因此需要網路連線；資料供應狀況、API 限制或服務異常可能影響結果。

## 計算範圍與限制

- 開始日或之後第一個交易日收盤買進；結束日或之前最後一個交易日收盤賣出。
- 以整股買進，未投入現金計入期末資產。
- 納入回測持有期間的現金股利及股票股利，以及買進／賣出手續費與證券交易稅。
- 不包含個人綜合所得稅、券商最低手續費、實際折扣與零股配發差異。
- 資料及公司行動可能修訂；結果為估算，不代表未來績效，也不是投資建議。

## 部署

本專案不需建置步驟。GitHub Pages 工作流程會將根目錄的 `index.html` 發布。

首次使用時，請到 repository 的 **Settings → Pages → Build and deployment**，將 **Source** 設為 **GitHub Actions**。之後推送至 `main` 即會自動重新發布。

## 比較回測使用方式

1. 開啟「比較回測」，輸入多個股票或 ETF 代號，以逗號分隔。
2. 選擇起訖日期，以及每檔的單筆金額或每次定期投入金額。
3. 按「開始比較回測」，結果會依淨報酬率排序。
4. 手續費可依券商折扣修改；交易稅欄留白時，代號以 00 開頭的 ETF 按 0.1%、其他股票按 0.3% 估算，也可手動輸入覆寫。

回測資料來自 FinMind，首次查詢需要網路連線。各標的資料會逐檔下載；來源服務限流或缺資料時，結果會標示該檔錯誤，不影響其他已完成標的。
